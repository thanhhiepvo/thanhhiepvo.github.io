## Deploying updates

1. Edit `index.html` or `README.md` as needed.
2. Commit and push to the branch used for GitHub Pages (currently `general`).
3. GitHub Pages will publish to `https://thanhhiepvo.github.io` after the build completes.

To enable or verify Pages: **Repository → Settings → Pages → Build and deployment → Source** — select the `general` branch and `/ (root)`.
