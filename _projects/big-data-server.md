A distributed Hadoop cluster built and configured from the ground up, used as a platform
for batch and streaming workloads.

**Batch.** MapReduce jobs over HDFS, plus Spark's Structured APIs (DataFrames and
Datasets) for the same workloads expressed declaratively.

**Streaming.** Spark Structured Streaming for continuous processing on top of the same
cluster.
