From-scratch implementations of three classical data-mining algorithms, written in both
Python and Julia to compare how each language handles the same numerical work.

- **Apriori** — frequent itemset mining and association rule generation.
- **ID3** — decision-tree induction using information gain as the split criterion.
- **K-Means** — centroid-based clustering on unlabelled data.
