From-scratch implementations of classical data-mining algorithms, written in both Python
and Julia to compare how each language handles the same numerical work. The pipeline
starts with a hand-rolled preprocessing stage rather than relying on a library.

- **Apriori** — frequent itemset mining over a transactional database, finding item
  combinations that occur together often.
- **ID3** — decision-tree induction using information gain as the split criterion.
- **K-Means** — centroid-based clustering on unlabelled data.
